共享缓存与实验口径

  • 复用前次5分钟实验通过的共享缓存实现，未叠加连续窗口分组。每 worker 对应7个共享解码槽位＋1个本地保留块，总保留预算仍为8块/worker。4 worker 时为28共享＋4本地块，约1.47 GB；实际 worker 数随原算法阶段决定。pending任务、解码与复制临时缓冲另计。
  • 块长60000采样点，每块384通道；同块并发任务使用 single-flight 锁，缓存命中安全复制复用。不同块仍可并行解码。缓存按 loader 隔离并释放，不跨算法阶段复用，不写出解压数据文件。
  • 同一原始30分钟 fixture，54,000,000采样点；正式运行前全部871个重叠窗口逐ADC比较，原始文件 SHA-256 与原测试一致，保留 CRC 校验和实际 DataLoader 消费顺序断言。
  • 同一源码快照、随机种子1、CPU线程8、RTX5090、GPU owner4 GiB，其余算法参数沿用原测试。新测每档独立进程、完整 API 到 single_session_quality_filter/export 与 GPU 同步。主曲线计时与历史 API 口径一致，排除导入和首次 CUDA 热身；另存包含 reader 收尾的计时。
  • 软件限速只计费原始或压缩输入字节，OS缓存命中仍计费；中间数据和输出读写不限速。没有物理SSD限速、没有模拟机械盘寻道，也没有清空OS文件缓存。
