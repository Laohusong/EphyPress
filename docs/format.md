# SPC lossless format and compatibility

EphyPress 0.1 writes SPC3/FSE by default and SPC1/Zstd when requested. It reads
lossless SPC1/SPC3 generated by the original Level1 implementation. Quantum must
be exactly 1; lossless predictor IDs are immutable and learned-model definitions
are compared with the registry recorded in each archive. SPC2/4/5 and lossy
quantization are deliberately rejected by this lossless package.

## Layout

All integer fields are little-endian.

1. A 24-byte prefix `<8sQQ>` stores magic, JSON index offset and index length.
   Magic is `SPKC01\0\0` or `SPKC03\0\0`.
2. Independently compressed frames follow the prefix.
3. A UTF-8 JSON index follows the frames.
4. A 32-byte SHA256 digest of the exact JSON bytes terminates the file.

Each frame index entry is `[byte_offset, byte_length, first_sample, last_sample,
crc32]`; sample ranges are half-open and include any stored halo. Shapes, dtype,
sampling frequency, block length, predictor/model, entropy mode, source byte
count and SHA256 are in the index. Index size is limited to 16MiB; use larger
blocks for very long files.

SPC1 frame header `<II>` stores low-plane bytes and Zstd bytes.
SPC3 header `<III>` stores low-plane bytes, channel packet bytes and Zstd
upper-plane bytes. FSE channel packets begin with `<I>` packet length and mode:
`0` = raw bytes, `1` = FSE stream, `2` = repeated symbol. The lowest four residual
bits are packed directly. The next eight bits use per-channel FSE; the highest
four bits are stored in the Zstd upper plane. Counts are padded internally to
multiples of eight; padding is never exposed as real samples.

## Default prediction

For each channel within a block, predict
`floor(10 * previous_sample / 16)`. The first sample uses predictor zero.
Subtract using reversible 16-bit modular arithmetic, then Zigzag-map the signed
residual. Decoder reverses Zigzag and adds the same predictor. Integer floor
division and wrapping are defined identically for negative values and extrema.
p53 has zero spatial weights; p41 additionally predicts residuals from the prior
four channels with weights `[7,11,2,4]/32`. This is compression, not filtering.

All blocks decode independently. Sorting batch sizes and halos are consumer
requests; they need not align with storage blocks. A source compressed from a
SpikeInterface recording may additionally contain `ephypress_metadata` for
channel IDs, selected channel properties, probe groups, time origin and filtered
annotation. Original readers ignore that optional field.

Archive bytes need not be identical across entropy-library or Zstd versions.
The contract is exact restored ADC bytes and compatible frame decoding. Index
SHA256 and block CRC detect corruption; full reconstruction SHA256 validates the
whole original stream. These checksums are not authentication signatures.
